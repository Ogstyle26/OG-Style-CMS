OG STYLE — VERSIONE CON CMS

Questa versione mantiene la grafica della V2 e aggiunge un pannello /admin.

IMPORTANTE: per il CMS il sito deve essere collegato a un repository GitHub e Netlify deve fare il deploy dal repository. Il file admin/config.yml contiene due placeholder da sostituire:
- YOUR_GITHUB_USERNAME/ogstyle
- https://YOUR-SITE.netlify.app

Dopo la configurazione, il pannello sarà disponibile su:
https://TUO-SITO.netlify.app/admin/

Dal pannello puoi modificare:
- testi della Home
- testi di Restauro
- testi di Chi siamo
- contatti, Instagram, WhatsApp ed email
- logo
- foto principale
- portfolio/mobili, inclusa aggiunta di nuovi lavori e foto

La grafica CSS e la struttura delle pagine restano separate dai contenuti.
